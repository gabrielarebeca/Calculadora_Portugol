# 🧮 Calculadora em Portugol

Este projeto é uma **calculadora simples desenvolvida em Portugol Studio**, voltada para operações matemáticas básicas. Ideal para iniciantes que estão aprendendo lógica de programação e algoritmos.

## 📌 Sobre o Projeto

A calculadora foi construída usando a linguagem de pseudocódigo do **Portugol Studio**, uma ferramenta educacional que auxilia na introdução à programação estruturada.

## ⚙️ Funcionalidades

- ➕ Adição  
- ➖ Subtração  
- ✖️ Multiplicação  
- ➗ Divisão  
- 🔁 Estrutura de repetição para novas operações  
- ⚠️ Verificação de divisão por zero

## 🛠 Tecnologia Utilizada

- **Portugol Studio**  
-  Ferramenta de pseudocódigo usada para aprendizado de lógica de programação.
